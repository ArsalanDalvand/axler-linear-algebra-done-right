# 📘 جبر خطی آکسلر به روش درست (Linear Algebra Done Right)
### پایگاه دانش اتمیک زتل‌کاستن (Obsidian Knowledge Base)

این مخزن شامل **پایگاه دانش اتمیک (Atomic Knowledge Base)**، ساختارمند و متصل بر پایه کتاب مرجع مشهور **Linear Algebra Done Right (ویرایش چهارم، ۲۰۲۴)** اثر **شلدون آکسلر (Sheldon Axler)** و ترجمه فارسی **دکتر مهدی نجفی‌خواه** است.

محتوای این پایگاه دانش برای **فصل اول (فضاهای برداری)** و **فصل دوم (فضاهای برداری با بعد متناهی)** به گونه‌ای بازطراحی شده است که یک دانشجو با پایه‌ی ریاضیات دبیرستان، بتواند تمامی قضایا، تعاریف، اثبات‌های دقیق بدون پرش محاسباتی و شهود هندسی را به طور خودآموز و عمیق فرا بگیرد.

---

## 🌟 ویژگی‌های برجسته مخزن

1. **متدولوژی یادداشت‌برداری زتل‌کاستن (Zettelkasten):**
   - تفکیک هر مفهوم، قضیه، تعریف و تمرین به یک یادداشت اتمیک مستقل (`.md`).
   - پیوند متقابل (Bidirectional Wikilinks `[[...]]`) برای ساخت شبکه گراف دانش در ابسیدین.
2. **پوشش ۱۰۰٪ و بدون جاافتادگی:**
   - تمام ۴۶ مفهوم/قضیه فصل ۱ و ۴۱ مفهوم/قضیه فصل ۲ همراه با شماره‌گذاری رسمی کتاب.
   - حل تشریحی ۱۰۰٪ تمرینات پایان بخش‌های فصول ۱ و ۲ (۹۸ تمرین کامل بدون جهش محاسباتی).
3. **پل پیش‌نیازهای دبیرستانی (Zero-Prerequisite Onboarding):**
   - ۱۱ یادداشت اتمیک اختصاصی برای مرور اعداد مختلط از صفر تا صد، مفهوم میدان $\mathbb{F}$، شهود هندسی بردارها، نماد سیگما، استقرا و دستگاه‌های معادلات.
4. **شبیه‌سازی‌های بصری و تعاملی با GeoGebra Lab:**
   - استفاده از بلوک‌های ساختاریافته تعاملی `geogebra` برای رسم بردارها، اسپن، صفحات و مقایسه زیرفضاها در ابسیدین.
5. **اثبات‌های گام‌به‌گام و تحلیلی:**
   - تمرکز ویژه بر شاهکار آکسلر: **لم وابستگی خطی (Lemma 2.19)** و اثبات قضایای بعد بدون استفاده از دترمینان.

## 🚀 راهنمای استفاده در ابسیدین (Obsidian)

1. این ریپازیتوری را کلون کرده یا محتوای آن را درون والت (Vault) ابسیدین خود کپی کنید:
   ```bash
   git clone https://github.com/ArsalanDalvand/axler-linear-algebra-done-right.git
   ```
2. والت را در **Obsidian** باز کنید.
3. برای رندر شدن شبیه‌سازی‌های هندسی، افزونه **GeoGebra Lab** را در ابسیدین فعال کنید.
4. مطالعه را از فایل `00-MOCs/00-MOC نقشه راه جامع جبر خطی آکسلر.md` آغاز کنید.

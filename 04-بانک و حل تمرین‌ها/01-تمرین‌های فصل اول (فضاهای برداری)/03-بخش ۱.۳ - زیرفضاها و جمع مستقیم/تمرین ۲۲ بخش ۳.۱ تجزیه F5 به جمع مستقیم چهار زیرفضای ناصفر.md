# تمرین ۲۲ بخش ۳.۱: تجزیه $\mathbb{F}^5$ به جمع مستقیم چهار زیرفضای ناصفر

> [!QUESTION] صورت دقیق مسئله (کتاب آکسلر)
> فرض کنید
> $$U = \{(x, y, x + y, x - y, 2x) \in \mathbb{F}^5 : x, y \in \mathbb{F}\}$$
> سه زیرفضا $W_1, W_2, W_3$ از $\mathbb{F}^5$ پیدا کنید، که هیچ‌کدام برابر $\{0\}$ نباشد، به طوری که
> $$\mathbb{F}^5 = U \oplus W_1 \oplus W_2 \oplus W_3$$

---

## ۱. تحلیل اولیه و باز کردن خواسته مسئله
* **داده‌های مسئله:**
  - فضای مادر $\mathbb{F}^5$.
  - زیرفضای دو‌بعدی $U$.
* **حکم مسئله:**
  - ساخت سه زیرفضای غیربدیهی ناصفر $W_1, W_2, W_3 \neq \{\mathbf{0}\}$ به طوری که جمع مستقیم ۴ زیرفضا کل فضا را تشکیل دهد.
* **چک‌لیست ابزارهای مورد نیاز:**
  - [[تعریف ۳۹.۱ جمع مستقیم (Direct Sum)|تعریف ۳۹.۱ جمع مستقیم]]
  - [[قضیه ۴۴.۱ آزمون جمع مستقیم برای چند زیرفضا|قضیه ۴۴.۱ آزمون جمع مستقیم برای چند زیرفضا (شرط بردار صفر)]]
  - [[تمرین ۲۱ بخش ۳.۱ یافتن متمم جمع مستقیم برای زیرفضایی در F5|تمرین ۲۱]]

---

## ۲. ایده و استراتژی حل (Problem-Solving Strategy)
* در تمرین ۲۱ دیدیم که زیرفضای سه‌بعدی $W = \{(0, 0, a, b, c) : a, b, c \in \mathbb{F}\}$ شرط $\mathbb{F}^5 = U \oplus W$ را برآورده می‌کند.
* اکنون کافی است این زیرفضای سه‌بعدی $W$ را به جمع مستقیم سه خط مختصاتی (سه زیرفضای یک‌بعدی ناصفر) روی محورهای سوم، چهارم و پنجم تجزیه کنیم:
  - $W_1$: خط روی محور مختصات سوم
  - $W_2$: خط روی محور مختصات چهارم
  - $W_3$: خط روی محور مختصات پنجم
* سپس با استفاده از قضیه ۴۴.۱ آکسلر، نشان می‌دهیم اگر جمع برداری از این ۴ زیرفضا برابر صفر شود، تک‌تک آن بردارها باید صفر باشند.

---

## ۳. حل تشریحی گام‌به‌گام (Step-by-Step Solution)

> [!PROOF] ساخت زیرفضاها و اثبات قضیه جمع مستقیم ۴ زیرفضا
> 
> **گام اول: تعریف سه زیرفضای $W_1, W_2, W_3$**
> سه زیرمجموعه از $\mathbb{F}^5$ را به صورت زیر تعریف می‌کنیم:
> 1. $W_1 = \{(0, 0, a, 0, 0) \in \mathbb{F}^5 : a \in \mathbb{F}\}$
> 2. $W_2 = \{(0, 0, 0, b, 0) \in \mathbb{F}^5 : b \in \mathbb{F}\}$
> 3. $W_3 = \{(0, 0, 0, 0, c) \in \mathbb{F}^5 : c \in \mathbb{F}\}$
> 
> **بررسی شرایط اولیه:**
> - هر یک از این سه مجموعه خطوط گذرنده از مبدا هستند و به وضوح زیرفضای $\mathbb{F}^5$ می‌باشند.
> - هیچ‌یک برابر با $\{\mathbf{0}\}$ نیستند؛ زیرا برای نمونه بردار پایه استاندارد $e_3 = (0, 0, 1, 0, 0) \in W_1$، بردار $e_4 = (0, 0, 0, 1, 0) \in W_2$، و بردار $e_5 = (0, 0, 0, 0, 1) \in W_3$ بردارهای ناصفر هستند:
>   $$W_1 \neq \{\mathbf{0}\}, \quad W_2 \neq \{\mathbf{0}\}, \quad W_3 \neq \{\mathbf{0}\}$$
> 
> **گام دوم: اثبات جمع مستقیم با آزمون بردار صفر (قضیه ۴۴.۱ آکسلر)**
> طبق قضیه ۴۴.۱، حاصل جمع زیرفضاها مستقیم است اگر و تنها اگر رابطه:
> $$u + w_1 + w_2 + w_3 = \mathbf{0}$$
> (که در آن $u \in U$ و $w_1 \in W_1$ و $w_2 \in W_2$ و $w_3 \in W_3$) نتیجه دهد:
> $$u = \mathbf{0}, \quad w_1 = \mathbf{0}, \quad w_2 = \mathbf{0}, \quad w_3 = \mathbf{0}$$
> 
> بردارها را به صورت مؤلفه‌ای باز می‌کنیم:
> - $u = (x, y, x + y, x - y, 2x)$ به ازای مقادیری از $x, y \in \mathbb{F}$.
> - $w_1 = (0, 0, a, 0, 0)$ به ازای $a \in \mathbb{F}$.
> - $w_2 = (0, 0, 0, b, 0)$ به ازای $b \in \mathbb{F}$.
> - $w_3 = (0, 0, 0, 0, c)$ به ازای $c \in \mathbb{F}$.
> 
> معادله جمع بردارها:
> $$(x, y, x + y + a, x - y + b, 2x + c) = (0, 0, 0, 0, 0)$$
> با مساوی قرار دادن تک‌تک مؤلفه‌ها با صفر:
> 1. مؤلفه اول: $x = 0$
> 2. مؤلفه دوم: $y = 0$
> چون $x = 0$ و $y = 0$ است، بلافاصله نتیجه می‌شود:
> $$u = (0, 0, 0, 0, 0) = \mathbf{0}$$
> 
> حال مقادیر $x = 0$ و $y = 0$ را در سه مؤلفه بعدی قرار می‌دهیم:
> 3. مؤلفه سوم: $x + y + a = 0 \implies 0 + 0 + a = 0 \implies a = 0 \implies w_1 = \mathbf{0}$
> 4. مؤلفه چهارم: $x - y + b = 0 \implies 0 - 0 + b = 0 \implies b = 0 \implies w_2 = \mathbf{0}$
> 5. مؤلفه پنجم: $2x + c = 0 \implies 2(0) + c = 0 \implies c = 0 \implies w_3 = \mathbf{0}$
> 
> بنابراین تنها راه تولید بردار صفر این است که تمام بردارها صفر باشند.
> این اثبات می‌کند که جمع $U + W_1 + W_2 + W_3$ یک **جمع مستقیم** است.
> 
> **گام سوم: اثبات پوشش کل فضا ($\mathbb{F}^5$)**
> هر بردار دلخواه $v = (v_1, v_2, v_3, v_4, v_5) \in \mathbb{F}^5$ را می‌توان به صورت زیر نوشت:
> $$v = \underbrace{(v_1, v_2, v_1 + v_2, v_1 - v_2, 2v_1)}_{\in U} + \underbrace{(0, 0, v_3 - v_1 - v_2, 0, 0)}_{\in W_1} + \underbrace{(0, 0, 0, v_4 - v_1 + v_2, 0)}_{\in W_2} + \underbrace{(0, 0, 0, 0, v_5 - 2v_1)}_{\in W_3}$$
> هر ۴ بردار به ترتیب به زیرفضاهای $U, W_1, W_2, W_3$ تعلق دارند.
> بنابراین:
> $$\mathbb{F}^5 = U \oplus W_1 \oplus W_2 \oplus W_3$$ $\blacksquare$

## ۴. دام‌های رایج در حل این تیپ مسئله
> [!WARNING] نکات باریک‌تر از مو
> - **تله آزمون اشتراک دو به دو:** برای بیش از دو زیرفضا، هرگز نباید از آزمون اشتراک دو به دو ($W_i \cap W_j = \{0\}$) استفاده کرد! طبق تذکر مهم بخش ۳.۱ آکسلر، ممکن است اشتراک دو به دو صفر باشد اما جمع مستقیم نباشد (مثال ۴۴.۱ آکسلر). برای بیش از دو زیرفضا، تنها ملاک معتبر **آزمون تجزیه یکتای بردار صفر** (قضیه ۴۴.۱) است.
